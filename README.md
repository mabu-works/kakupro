## 📖 概要

実在しない架空の人物のプロフィールを、ワンボタンでランダム生成する静的Webツールです。生成結果はブラウザの中だけで作られ、外部に送信されません。

## ✨ 機能

### プロフィール生成
生成される項目は次の8つです。

- **名前**：姓（31種）と名（30種）の組み合わせで生成
- **年齢**：6〜89歳のランダム
- **職業**：36種のプールから選択
- **特技／好きなもの／苦手なもの／口癖／一言コメント**：各16〜20種のプールから選択

### 固定（ロック）と再抽選
- 各項目に「固定」チェックがあり、固定した項目は「再生成（固定以外）」を押しても変わりません。
- 「全部ランダムに作り直す」は固定を無視して全項目を引き直します（固定チェック自体は保持されます）。
- 各項目の「再抽選」ボタンで、その項目だけを引き直せます（固定中でも引き直せます）。

### 共有
- **カード画像**：名前と各項目を載せたプロフィールカード（1200×630 PNG）を Canvas で描画し、ダウンロードできます。画面上にプレビューも表示されます。
- **テキストコピー**：X投稿向けの整形テキスト（項目を「ラベル：値」で並べ、末尾に `#kakupro`）をワンクリックでコピーできます。コピーされる内容は画面で確認できます。

### その他
- PWA対応（ホーム画面に追加可能、オフラインでも動作）。
- テーマはダークが既定で、右上のボタンでライトに切り替えできます（選択は端末に保存されます）。

## 📝 使い方

1. ページを開くと、まず1人分のプロフィールが生成されています。
2. 気に入った項目は「固定」にチェックを入れ、「再生成（固定以外）」で他の項目だけを引き直します。
3. 共有したいときは「カード画像をダウンロード」か「テキストをコピー」を使います。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。データプール（姓31種・名30種・職業36種など）と項目ごとの固定・再抽選、カード画像（1200×630 PNG）の保存、X投稿向けテキストのコピーまで Web 版と同じです。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Kakupro.exe` を生成
- ダウンロード: [GitHub Releases（Windows版 v1.0.0）](https://github.com/mabu-works/kakupro/releases/tag/v1.0.0)
- カード画像は保存ダイアログで保存先を選ぶ方式で、画面上のプレビューはありません

## 📋 技術メモ

- ビルド不要の静的サイト（素の HTML / CSS / JavaScript、外部リソース不使用）。
- 状態は項目ごとの `{ value, locked }` を保持し、再生成・再抽選・固定はすべてこの状態に対して操作しています。
- Service Worker（`sw.js`）が同一オリジンのGETリクエストを `kakupro-v2` キャッシュに保存します。
- アイコンは PIL で生成した PNG（角丸の teal 背景に白い「架」の文字）。
